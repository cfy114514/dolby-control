# 0.6.2 代码审查与整理

本轮对完整应用源码、原生 helper、测试、构建脚本、Manifest、资源及 LSPosed 元数据进行了首轮审查和独立交叉复查。原 0.6.1 已安装版本作为本地可回退基线保留。不是对所有可能故障的保证。

## 修复和优化

| 范围 | 问题与处理 |
| --- | --- |
| 后台请求 | 固定线程池原有无界队列；改为有限队列，外部 UID 在入队前拒绝。请求总期限覆盖 socket 排队、读取和主线程排队；已过期且尚未开始的操作不会稍后修改音效。已开始的事务允许安全完成。 |
| 外部 helper | 子进程可能无限阻塞；增加总超时、输出上限和退出确认。无法确认已退出时不启动竞争恢复。 |
| 重装与启动 | 两次安装同一构建仍有不同 APK 路径；所有启动确认同时检查构建身份与安装路径，并等待旧后台退出。启动预算包含竞争等待。 |
| 参数草稿 | 读取或应用失败后禁用旧表；Activity 重建保留草稿。提交包含档位、参数基线及音频进程身份，陈旧编辑拒绝写入。 |
| 用户提示 | 将保存成功、等待激活、DSP 未确认与实际观察到生效分开，不再把表写入直接显示成实时生效。 |
| 页面生命周期 | SoundAlive 页面暂停和销毁时取消轮询；返回后恢复。普通原生切档在独立后台不可用时保持原生行为。 |
| 连续切档 | 手选和重新确认各只保留一个正在执行及一个最新待执行请求，丢弃中间选择，并按原始点击时间计算期限。后台未确认保持时显示明确提示。 |
| 档位重载 | 临时切到其他档位以重新加载参数时，固定入口档位和输出设备。恢复失败后仍以入口为恢复目标，不把临时档位误当作原档位；路由变化或关闭杜比时停止写入。 |
| 原生事务 | 状态读加入共享锁，避免读到本工具写入中间态。库哈希和映射身份来自同一个已打开文件。解析失败整批作废，补齐边界校验。 |
| 原生回滚 | 不覆盖可识别的第三方后写值；失败短写只恢复可能属于本次写入的字节前缀。无法确认的恢复明确标记不完整。 |
| 跨层恢复 | Java 不再无条件全表恢复；尊重原生失败回执，只比较恢复本次改动目标。原生新增固定范围的条件恢复，在锁内先核对所有预期值，冲突时零写入。 |
| 性能 | 合并密集播放事件的重复重试，去掉恢复流程中重复的原生状态子进程；保留批量调参和直接使用返回参数表的机制。未宣称未经测量的耗电或耗时改善。 |
| 工程 | 独立 Git 仓库、可读后台代码、统一版本与工具发现、SHA256 锁定编译依赖、自动重编原生资产、生成身份放入 build、签名路径保护、Windows/Linux CI、许可和开发说明。 |
| 开发工具 | 导入验收脚本不会操作手机；变更设备状态的脚本需显式运行。多设备可指定序列号；证据均保留在忽略目录。 |

## 覆盖与边界

宿主回归直接调用实际 C++ 事务/解析实现，以及实际纯 Java 子进程、协议帧、队列期限和锁组件。整包构建、APK 内 helper 哈希、Xposed 入口/作用域及公开文件清单另行检查。公开 CI 使用干净检出，不依赖开发机的私钥或原厂二进制。

本机还用未修改的外部 SYSTEM 库核对了 44 个固定槽位、完整前缀、原厂值、范围和渲染记录排除。该专有库不上传；公开 CI 会明确跳过需要该库的检查。

### 0.6.2 真机验收

本轮将原签名的 0.6.2 安装到上述 S23，核对安装包哈希与本地构建一致，后台构建身份为 `e0e29f797f3fbffae81863fd`。以下均为本轮结果，原始设备证据仅保留在忽略的 `build/`：

- 系统第五行正常；Music/Spatial 切换、连续快速切档后以最后一次选择为准，暂停及恢复播放后仍保持 Spatial。
- Spatial 档的对白增强、智能均衡、数值强度及共用目标值在实际 DSP setter 中观察到对应变化；Music 的增强开关保持独立。无效档位及超出范围的值被拒绝。
- 在声音调节页实际点击“应用调整”后，Music 参数表发生预期变化，页面显示已应用。
- 旋转到横屏再回竖屏，草稿仍保留且未写入参数表；去系统页切换档位再返回，陈旧草稿被清除。
- 后台拒绝档位、参数基线及音频进程身份不匹配的编辑，44 项参数未被修改。
- 在 Android 真正的文件锁、SYSTEM 映射及 `/proc` 路径上执行原生条件恢复：预期值冲突时零写入；匹配时单项修改和恢复成功。
- 原生关闭杜比后，暂停/播放和重新确认不主动开启它；原生重新开启可恢复 Spatial。手选 Auto 释放保持，播放及切歌不强制改成 Music。
- 覆盖安装同一构建使安装路径改变，受保护的包更新事件重启独立后台后，档位和全部 44 项参数保留。重新启动 SoundAlive 页面仍保持 Spatial。

结束时再次对比入口记录：44 项参数、“关闭增强”、手选 Spatial、原生杜比开关和旋转设置均恢复；播放恢复为暂停。

本次连接开始时出现过“原生杜比开关开启，但空间处理器未激活”；通过原生开关关闭再开启后恢复。模块没有用自动开启杜比的方式绕过此状态。0.6.1 历史验收包括 AirPods 和 Apple Music Dolby Atmos；本轮使用 Apple Music 验证播放事件，但未重新确认 AirPods 实际路由及 Atmos 曲目标志，不能把历史证据算作本轮这两项已经验收。

尚未在本轮真机覆盖：离开 SoundAlive 后的轮询次数测量、请求过载及所有启动竞争、整机重启、耳机断连重连。这些路径中的期限、队列和恢复组件有宿主回归，但不能替代设备上的完整场景。后台重启测试不能替代整机重启。锁只能协调本工具，任意外部 Root 写入只能尽力检测，不能提供完整隔离。

当前适配范围和 DSP 平台限制保持：固定固件、44 个可写槽位、独立 Spatial Audio 渲染、DDP/Atmos 强制 `dvle=0`。没有新增固件或机型支持。
